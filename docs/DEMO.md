# Demo plan

## Current status

The app is not ready for a product demo: Builder A's backend, selected model, real indexing, and native file actions are not available in this checkout. Do not present a fixture as a real search or claim model speed/quality from the interface build.

## Planned short demo (about 55 seconds)

1. **0–8s:** Show several synthetic files with unhelpful names and describe the missing laptop repair receipt.
2. **8–18s:** Select the synthetic folder and show real local indexing progress. Disclose any time cut.
3. **18–35s:** Search naturally, show the matching filename, source excerpt, and open the original.
4. **35–48s:** Add a fresh synthetic file, disable the network, index and search it, and show actual local inference activity.
5. **48–55s:** Say why local search helps protect private files. Use the confirmed event hashtag and organizer tag only after checking current organizer requirements.

Keep the live-demo corpus small and varied; use a separate large corpus for scale results. Prepare a backup recording and five-minute pitch. Never record personal documents or the local search index.

For the first TXT-only integration, `python demo/generate.py` creates varied synthetic files in ignored `demo/generated/` and writes the expected-task manifest to `demo/manifest.json`. PDF and screenshot corpus generation waits for agreement on the project's available PDF/image dependencies.
